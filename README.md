# EventMemories-AI

🚀 AI-powered photo-sharing and event-management platform for event and wedding memories. Guests scan their face live to instantly find and download their memories.

## Tech Stack

- **Backend:** FastAPI (Python)
- **Face Recognition:** OpenCV + SFace (machine-learning)
- **Frontend:** React (Vite)
- **UI/UX:** TailwindCSS + Framer Motion

## Keywords
